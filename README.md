# QuizRPG Demo

学習問題を解くこと自体が戦闘操作になる、ブラウザ向けクイズRPGのプロトタイプです。

## コンセプト

- RPG本編は長編を想定し、ゲーム進行に合わせて敵やエリアが変化
- 最初に選ぶ学習セット1つは無料
- 2つ目以降の学習セットは製品版では買い切り課金を想定
- RPG進行度と各学習セットの習熟度は分離
- 正解で敵へ攻撃、不正解でプレイヤーがダメージ
- 間違えた問題は復習キューに入り、数問後に再出題
- 学習セット内では回答実績に応じて Learning Tier が上昇
- スマートフォンでも遊べるレスポンシブUI
- 外部ライブラリ・ビルド工程なし

## 収録デモ学習セット

- 中学英語
- 日本史
- 中学理科
- 中学数学

デモでは最初の1セットだけを無料選択できます。追加セットは学習セット変更画面から「デモ購入」をシミュレートしてアンロックできます（実際の決済は発生しません）。

## 起動方法

`index.html` をブラウザで開くだけで動作します。

ローカルHTTPサーバーを使う場合:

```bash
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開いてください。

## 今後の実装候補

1. 問題データをJSON/APIへ分離し、数千〜数万問に拡張
2. 問題ごとの正答履歴・最終回答日時・忘却度を保存
3. SM-2等を参考にした間隔反復アルゴリズム
4. マップ、町、装備、スキル、ボス戦、ストーリーの追加
5. 問題セット購入・復元購入
6. アカウント同期・クラウドセーブ
7. AIを使った問題生成支援と、人間/AIによる品質検査パイプライン
8. Web版からCapacitor等を利用したiOS/Android展開

## デモ上の注意

このリポジトリはゲームループとUI検証用のプロトタイプです。問題数、課金、学習アルゴリズム、セーブ同期などは本番仕様ではありません。
